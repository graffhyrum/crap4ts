# Changesets

Hello and welcome! This folder has been automatically generated by `@changesets/cli`, a build tool that works with multi- and single-package repositories, to make versioning and publishing software easier. Changesets enables contributors to declare how their changes should be released, then we automate updating package versions, change logs and publishing new versions of packages based on the provided information.

We have a guide for [getting started using changesets from scratch](https://github.com/changesets/changesets/blob/main/docs/intro-to-using-changesets.md) if you want a full walkthrough, but to get up and running:

1. Make changes to the codebase
2. Run `bun run changeset` and follow the prompts to describe the change
3. Commit the generated markdown file in `.changeset/`
4. Open a PR to `main`

When the release PR is merged (created automatically by the Release workflow), packages are versioned and published to GitHub Packages.
