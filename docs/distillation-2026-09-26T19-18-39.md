## Patterns Worth Repeating

- **Pattern**: Product tag before delete
  **Condition**: A complexity audit ranks a README or CLI feature for deletion
  **Summary**: Tag it `product:` and wait for confirmation.

- **Pattern**: Filter after summarize
  **Condition**: A report shows a subset and also prints totals
  **Summary**: Compute totals on the full set. Filter only the rows you print.

- **Pattern**: Same-command repro
  **Condition**: A gate script fails
  **Summary**: Re-run that command after the fix. Re-read the script if it changed.

- **Pattern**: Double-glob for gitignore coverage
  **Condition**: Converting gitignore patterns to Bun `Glob` patterns
  **Summary**: Emit both `base` and `base/**` so files and directory contents match. Absorbed from `distillation-2026-03-09T00-00-00.md`. `br remember` is not a `br` command.

- **Pattern**: `makeFs()` factory
  **Condition**: Unit tests for a module that takes `FileSystem`
  **Summary**: Default `exists` and `readText` to the empty case. Override one signal per test. Absorbed from `distillation-2026-03-09T00-00-00.md`.
