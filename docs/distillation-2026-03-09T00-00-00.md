## Applied Changes

### Rules (AGENTS.md)
- **Rule**: CLI tools throw typed errors in library code, catch only at `src/index.ts`.
  **Source**: post-mortem-initial-implementation (3/3 expert consensus)
  **Rationale**: `process.exit` in library code blocks testing and was the top expert review finding.

- **Rule**: New modules needing file I/O must accept `fs: FileSystem = bunFileSystem` — use `src/detect/types.ts` interface.
  **Source**: post-mortem-init-detection + post-mortem-gitignore-filtering (2 post-mortems)
  **Rationale**: DI seam enables zero-filesystem tests; pattern established in `detect/` should be extended everywhere.

- **Rule**: Before adding required fields to `Config`, grep test files for direct literal construction.
  **Source**: post-mortem-gitignore-filtering
  **Rationale**: tsc won't surface this until compile time; a 10-second grep prevents surprise failures.
